# Acceptance and falsifiers

- Parent binds named request/tool/config/source/environment into budget scope
  before capacity/lease/product start; bad requests refuse before allocation.
- Eight exact commands preserve arguments/default profiles/targets and strict
  lint exceptions. Fixed nine-package order stays intact; no-run and runtime
  remain different requests.
- Child cannot use an unenumerated known row, raw args, alias or runtime fallback.
- Replaced lease/marker, stale snapshot/descriptor/source/tool/config, wrong
  ancestry, changed resources/jobs/temp/selectors/flags/network/build inputs
  refuse before resource-bearing execution.
- Docs-only raw/encoded flags cannot qualify an ordinary build/Clippy request.
- Declared and configured cap-lints/suppression cannot turn strict proof green.
- Existing outer owner alone settles/release; product status remains separate.
- Missing aggregate inventory/capacity/binary-handoff/host proof stays explicit.

Cheap mutation controls remove membership, replace dynamic lint rendering with
pilot constants, ignore marker identity, mask docs encoded flags, trust declared
cap-lints and omit doc-flag freezing. Each must fail by a semantic assertion,
not instrument error. Existing owner/driver/platform controls remain applicable.
