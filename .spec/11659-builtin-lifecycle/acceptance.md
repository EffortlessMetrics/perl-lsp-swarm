# Acceptance

- Builtin Linux launches reuse the existing exclusive owner, without changing
  the admitted Cargo command, toolchain selection or storage/capacity policy.
- Detached surviving helper after exit 0 or 101 retains the lease until closure;
  a known leader-only implementation fails this discriminator without test errors.
- Deadline/ambiguous closure and failed release return 75 with ownership retained.
- Cancellation after proven closure and release returns 130, never product success.
- Original lease identity and marker, operation-labelled product and kernel
  settlement receipts remain independent and attributable.
- Missing Linux capabilities refuse without spawning through legacy fallback.
- Non-Linux legacy statuses/interruption stay unchanged and do not claim closure.
- Real offline A/B/A private-state behavior is 1/2/1 with kernel settlement and
  matching release for each Linux launch; prior Clippy/driver controls still pass.
- Old resources remain untouched; no canonical executor, Windows, Ready, merge or
  expensive hosted CI claim is added.
