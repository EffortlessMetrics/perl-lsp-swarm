# Changelog

All notable changes to the EffortlessMetrics Claude Code Perl LSP plugin are recorded here.

## 0.1.0

- Added the first-party native LSP package for `perllsp`.
- Bound the server workspace to `${CLAUDE_PROJECT_DIR}`.
- Added bounded Perl activation for `.pl`, `.PL`, `.pm`, `.t`, `.psgi`, `.cgi`, and `.fcgi`.
