# PERLLSP-SPEC-0009: Parser gap closeout

## Contract

A parser gap is not closed merely because a test lands. Closing a gap requires:

```text
ledger status update
fixture or accepted-impossible rationale
proof command
claim boundary
docs update if public claim changes
closeout note for P0/P1 or behavior-changing fixes
```

## Closeout path

```text
.perl-lsp-spec/closeouts/<date>-parser-gap-<slug>-closeout.md
```
