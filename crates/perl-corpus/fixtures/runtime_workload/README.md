# Attributed runtime workload

Owner: #17536 under #17511 / #17509. **One real-corpus workload with provenance,
frozen stock-Perl observations, reserved hold-outs, and a source-to-stage
admission matrix. Not an executable profile, EIR/native conformance result,
speedup claim, or application-compatibility claim.**

The workload is `spectralnorm.perl`: spectral-norm Perl #1 from The Computer
Language Benchmarks Game (55 lines, `use strict` only, argv-in, one `printf`
line out). Full pin, extraction transform, hash, and license: `PROVENANCE.md`
and `LICENSE-benchmarksgame`. The `workload.t` driver runs the exact vendored
bytes on stock Perl against frozen expectations. Its use of `Digest::SHA`,
`IPC::Open3`, `FindBin`, `File::Spec`, `Config`, and TAP does not claim those
operations for the proposed runtime.

## Run

From the repository root on the first qualified Linux cell:

```sh
env -u PERL5OPT -u PERL5LIB -u PERLLIB LC_ALL=C \
  prove -v crates/perl-corpus/fixtures/runtime_workload/workload.t
```

Windows (PowerShell):

```powershell
$env:PERL5OPT=$null; $env:PERL5LIB=$null; $env:PERLLIB=$null; $env:LC_ALL='C'
prove -v crates/perl-corpus/fixtures/runtime_workload/workload.t
```

A workload-byte change, missing provenance field, lost license grant, changed
tuning set, output mismatch, nonzero exit, stderr output, or the 60-second
driver deadline (Unix only; MSWin32 has no `alarm`) fails the test. No Rust
build, editor request, or ordinary LSP activation invokes this command. It is an
explicit proof route, not yet an automated CI gate.

## Frozen inputs and observations

Tuning inputs are frozen; hold-out identities are reserved records with fixed
comparison rules and ungenerated expectations. Nothing may tune backend
thresholds or paths on hold-out results.

| Input | Expected stdout | Observed on |
|---|---|---|
| N=100 | `1.274219991` | perl 5.42.0 MSWin32 x86_64; perl 5.38.2 x86_64-linux (both 8-byte IV/NV) |
| N=200 | `1.274223601` | perl 5.42.0 MSWin32 x86_64; perl 5.38.2 x86_64-linux (both 8-byte IV/NV) |
| N=5500 | `1.274224153` | upstream published (perl 5.40.0 x86_64-linux, 2025-01-16); reproduced locally on 5.42.0 (one-time validation, not a gate: ~40s) |

Hold-outs: N=150, N=300. Expectations are generated by stock Perl at evaluation
time, never tuned against. The driver asserts the tuning set is exactly
{100, 200}, unknown inputs are outside it, hold-outs are disjoint from it, and
the fixed plan fails on an empty tuning set. The numeric line is compared after
CRLF-to-LF normalization (stock Perl on Windows emits `\r\n`); the number is
exact on every cell. A hosted cell that disagrees at the 9th decimal is a real
observation to record (float formatting is version/build sensitive); it is never
fixed by weakening an assertion.

## Source-to-stage admission matrix

One row per workload entry/feature. Every row resolves to a candidate family
with exact remaining prerequisites or an explicit unsupported boundary. **Zero
rows are admitted**: admission needs the accepted #17510 profile and the
family's own proof. Do not read this table as execution readiness.

| Workload subject | Stages / owners | Disposition |
|---|---|---|
| Program entry, `@ARGV` read, exit status | #2348 / #2354; profile #17510; lowering #17512 | Candidate; blocked on accepted #17510 decision and #17512 seam |
| Lexical scalars/arrays, `my`, assignment | #2413 / #2351 | Candidate; value/place prerequisites |
| Nested direct calls, scalar/list projection | #17513 / #2351 | Candidate; call/context prerequisites |
| `map BLOCK LIST` | #2350 | Prerequisite: list-iteration op unadmitted |
| Statement-modifier `for`, ranges, `$#_` | #2350 / #2413 | Prerequisites: loop/range/index facts |
| `**`, `sqrt`, `printf %0.9f` | #2413 / #2348 | Prerequisites: float ops and exact decimal formatting |
| `use integer` / `no integer` scoping (integer division in `eval_A`) | #2413 + pragma owner | Prerequisite: scoped arithmetic mode |
| `@_` indexing, post-increment in subscript | #2413 / #2351 | Prerequisites: argument-cell and order facts |
| `strict` pragma (load-bearing for the run) | pragma owner | Prerequisite: model or explicitly exclude |
| Whole workload as one entry | #17511 cohort; oracle #17535 | Candidate; no EIR/native row exists |

The workload was selected to contain no `eval`, regex, objects, magic, dynamic
or general-purpose module loading (`require`/`use` of runtime libraries), XS, or
file I/O. The only module load is the compile-time `use strict` pragma, which
has its own prerequisite row. This slice therefore adds no new
explicit-boundary rows beyond the prerequisites above; later workloads will. For #17533: the
repeated-call shape is present (`eval_A` runs O(N^2) times per run); a one-shot
hot-loop shape is absent and remains a recorded gap for a later workload, not an
implied property of this one.

## Proof discrimination

Expected outputs are literal frozen observations, independently reproduced on two
cells and against the upstream published value; they are not generated by a
candidate runtime. The driver fails closed: tampered workload bytes fail the
hash gate, an empty tuning set fails the fixed plan, unknown inputs have no code
path to execution, and a missing stock Perl is an instrument failure rather than
a pass. These checks do not prove any Rust/native implementation; #17522 owns
that qualification.
