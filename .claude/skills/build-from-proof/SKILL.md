# Build from proof

Confirm the issue, proof, writer/worktree, semantic owner, consumers, and real overlap. Implement through existing owners and production seams. Make reasonable documented decisions and proceed.

## Routes

- `IMPLEMENTATION_COMPLETE` → `improve-test-suite`
- `PROOF_INADEQUATE` → `prepare-proof`
- `MATERIAL_PREMISE_CHANGED` → `prepare-issue`
- `WRITER_COLLISION` / `UNSAFE_WORKTREE` → stop for the mechanical hazard
- `NOT_PROVEN` → preserve the missing authority or instrument
