# PERLLSP-SPEC-0023 — LSP Latency Receipts and Budgets

## Goal
Define measurable latency evidence and advisory budget policy.

## Includes
- policy file for latency budgets
- receipt schema
- raw RPC and Neovim lean receipts
- verifier command and advisory CI lane

## Dimensions
raw-rpc vs neovim; normal vs e2e; debug vs release; diagnostics mode; semantic tokens on/off; file watchers on/off; workspace shape; file-size class.

## Claim boundary
Receipts must document what they prove and what they do not prove.
