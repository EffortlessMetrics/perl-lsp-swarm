# Configuration

Configuration options live in the canonical reference, kept in sync with the
server, CLI, environment, VS Code, and DAP contracts.

See the [configuration canonical reference](../reference/configuration-canonical.md)
for the complete setting list, defaults, precedence rules, project configuration
examples, and troubleshooting guidance.

For a quick start, commit `.perl-lsp.toml` at the workspace root for shared
project defaults, or configure the `perl` namespace in your editor's LSP
workspace settings for user, workspace, or folder-specific behavior. The
canonical reference is the source of truth for the exact keys and channels.
