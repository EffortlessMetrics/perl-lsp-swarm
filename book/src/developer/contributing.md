# Contributing to Perl LSP

`EffortlessMetrics/perl-lsp-swarm` on `main` is the active product-development and
product-proof authority. Public contribution ingress, public release lineage, and published
artifacts live in
[`EffortlessMetrics/perl-lsp`](https://github.com/EffortlessMetrics/perl-lsp) on
`master`.

External contributors should open issues and pull requests against `perl-lsp`; they do
not need write access to swarm. Before integrating a shared-product public PR, maintainers
first reconcile accepted swarm state into the public repository, then reconcile the merged
shared-product effect back into swarm.

Use the canonical guides rather than a copied workflow that can drift:

- [Public contributing guide](https://github.com/EffortlessMetrics/perl-lsp/blob/master/CONTRIBUTING.md)
- [Swarm contributor topology](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/CONTRIBUTING.md)
- [Your first pull request](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/contributing/FIRST_PR.md)
- [Product and repository identity](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/reference/product-identity.md)

A swarm merge, a public contribution merge, and public release/channel availability are
separate states.
