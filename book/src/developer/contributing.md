# Contributing to Perl LSP

Active development happens in
[`EffortlessMetrics/perl-lsp-swarm`](https://github.com/EffortlessMetrics/perl-lsp-swarm)
on `main`. Public release lineage and published artifacts remain in
[`EffortlessMetrics/perl-lsp`](https://github.com/EffortlessMetrics/perl-lsp)
on `master`.

Use the canonical repository guides rather than a copied workflow that can drift:

- [Contributing guide](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/CONTRIBUTING.md)
- [Your first pull request](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/contributing/FIRST_PR.md)
- [Product and repository identity](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/reference/product-identity.md)

A merge to `perl-lsp-swarm/main` is development state, not proof that a change has
entered a release, package registry, editor marketplace, or other public channel.
