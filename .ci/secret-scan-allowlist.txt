# Secret-scan path allowlist (issue #17428).
#
# The pre-commit / pre-push hooks and the required secret_scan gate refuse
# token-shaped additions. This file is the documented escape for INERT test
# fixtures that must carry token-shaped bytes (for example, a fixture proving
# a redaction path, or the scanner's own regression corpus).
#
# One repo-relative path per line. Blank lines and lines starting with '#'
# are ignored. Matching is exact: there are no globs and no inline comments.
# A listed path is skipped by the hook scan and the gate alike, so entries
# must stay rare, fixture-shaped, and inert — never a live credential, and
# never a whole directory of them.
#
# Prefer fragment-built fakes (see the scanner's own tests and
# scripts/tests/traps/t03_secret_publish.sh) over listing a path here: a
# fake assembled at runtime never needs an exemption.
