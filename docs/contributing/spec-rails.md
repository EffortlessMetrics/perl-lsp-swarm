# Contributing: Spec Rails

## Durable locations

- `.perl-lsp-spec/` — proposals, specs, ADRs, and lane trackers.
- `docs/` — human-facing workflow and style guidance.
- `policy/` — live policy ledgers.

## Parser differential fairness policy

When writing parser comparison docs or status updates:

1. Label historical vendored comparisons as historical.
2. Avoid broad parser-family claims without current-target receipts.
3. Require parser-target-registry receipts for current upstream claims.
4. Keep rails/process changes separate from parser behavior changes.
