# v0.18 release topology

`release_topology.v1` is the exact-SHA inventory consumed by release
preparation, install-transition rehearsal, artifact integrity, and channel
verification. It is an inventory, not a release-readiness verdict and not
permission to publish.

Generate it only from the frozen/prepared checkout:

```powershell
python scripts/generate_release_topology.py `
  --release 0.18.0 `
  --frozen-product-sha <40-hex-freeze-sha> `
  --prepared-swarm-sha <40-hex-prepared-sha> `
  --output release_topology.v1.json
```

The generator derives the crate allowlist and topological order from Cargo
metadata, the binary target/archive matrix from `.github/workflows/release.yml`,
the VSIX identity from `vscode-extension/package.json`, and source hashes from
the checkout. It refuses to emit a manifest when any of those authorities
disagree. In particular, the current tree is intentionally `NOT_PROVEN` until
the workspace is prepared as `0.18.0`, and the current workflow/archive
contract mismatch for `aarch64-pc-windows-msvc` must be reconciled first.

Validate an existing manifest against the exact checkout and freeze SHA:

```powershell
python scripts/generate_release_topology.py `
  --check `
  --release 0.18.0 `
  --frozen-product-sha <40-hex-freeze-sha> `
  --output release_topology.v1.json
```

The JSON schema is [`schemas/release_topology.v1.schema.json`](../../schemas/release_topology.v1.schema.json).
