# v0.18.0

## Release definition

`v0.18.0` is the next public-beta release on the existing support line. It is
not a maturity promotion or a beta-entry ceremony.

## Product surface

- Primary UX: VS Code/VSCodium extension with a managed `perllsp` binary.
- CLI: `perllsp --stdio` and `perllsp --doctor`.
- The parser stack is a shipped component of the public-beta product.
- DAP remains preview within the public-beta distribution.

## Release rails

- Development authority: `perl-lsp-swarm/main`.
- Release authority: `perl-lsp/master`.
- Primary channels: GitHub, crates.io, VS Code Marketplace, and Open VSX.
- Freeze, package, build a release candidate, publish, and verify each channel
  independently. This planned record does not claim publication.

## Known limitations

Keep known limitations, refusal boundaries, and the DAP preview boundary
explicit in the candidate notes and channel copy.
