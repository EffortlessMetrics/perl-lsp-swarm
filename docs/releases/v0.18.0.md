## Summary

This release continues the compiler-backed toolchain build-out and matures the
public-beta surface. The parser/lexer/grammar stack absorbed a very large
correctness sweep (heredocs, quote-like operators, string repetition, indirect
calls, signatures and contextual assignment, POD boundaries, CRLF/UTF-16
offset exactness), navigation/completion/diagnostic answers became honest
about freshness and confidence, and the native `perl-dap` debugger was locked
to a single stdio transport with stale-evidence rejections across its request
surfaces. The compiler substrate advanced another step (field-level AST
offset registry, lexical fact envelopes, deterministic AST schema identity,
body-HIR lowering fidelity) without claiming a broad live-provider cutover.

Breaking changes concentrate on intentional pre-1.0 surface cleanups: sealed
token geometry and module facades, retirement of dead public surfaces
(`RefactoringEngine`, the duplicate `perl-lsp` executable, the
`Perl::LanguageServer` DAP proxy, the `compat` formatter mode), installer
product-unit verification, and security-driven transport restriction in the
debugger. Editor integrations (Neovim, Vim, Sublime, Zed, Helix, LSP4IJ) are
now backed by fail-closed, receipt-producing host journeys instead of
unearned support claims. Project configuration can no longer grant itself
security-sensitive authority (AI completion, absolute include paths, legacy
Critic profiles).

## Breaking changes and migration

Product:

- **perl-module implementation modules are private**; the facade is the
  supported surface (#12257).
- **Public perl-token geometry is sealed** (`Token`/`TokenRef`/`TokenSpan`
  fields private, read accessors only) and **token constructors now require
  source-text byte length to equal span width** (#12725, #12765).
- **`LexerCheckpoint` is an opaque, versioned live-boundary snapshot**;
  production capture comes only from a live lexer (#14896).
- **Regex provenance (`qr//`, `m//`, bare `//`) is preserved in the AST**, so
  constructors/matches that conflated the three forms must distinguish them
  (#16512).
- **Scalar signature defaults (`=`, `//=`, `||=`) parse exactly** with ranges
  retained; positional/named/slurpy ordering is enforced (#16204, #16208).
- **`DiagnosticCode` iteration and serde use the stable `PL###` registry
  identity** (#13867).
- **The `compat` formatter mode is retired** from the public contract (#15621).
- **`SemanticQueryFacade` is strictly per-file**; the cross-file
  `visible_in_*` view is gone (#15633).
- **`perl-lsp-rs-core::protocol::JsonRpcError` no longer implements
  `perl_parser_core::ErrorClass`** (#13071).
- **`perl-position-tracking` refuses to substitute a synthetic URI** for a
  `WireLocation` without one (#14811).
- **Pragma snapshots expose distinct bounded Perl 5.42/5.44 declaration
  profiles** (#13149).
- **The experimental tree-sitter semantic overlay is non-default** (#7603).
- **The runtime-module clock advances only inside the reload transaction**;
  out-of-band bumps are gone (#14635).
- **The absorbed filesystem-mutating `perl_parser::refactor::refactoring`
  module (`RefactoringEngine`) is removed** (#5231).
- **The duplicate `perl-lsp` executable is retired** from the
  `perl-lsp-rs` implementation crate — installers and docs ship `perllsp`
  (#7497).
- **The historical `Perl::LanguageServer` DAP proxy and bridge mode are
  removed** (#6991).
- **`perllsp --doctor --dev-environment`** reports Windows symlink
  privilege and related prerequisites; its report shape is versioned (#12664).
- **Native perl-dap no longer binds an editor-facing TCP listener**:
  `--socket`/`--port` fail before bind and external-peer modes expose DAP only
  over child stdio (#12641, #12723, #12573).
- **Generic client `testRunner` executable/argv/timeout authority is
  removed** (#11845).
- **Diagnostics and code actions share native Critic settings and service
  routing**; the split public paths are gone (#15418, #14566 — an external
  debugger peer's failure is no longer classified as an adapter bug).
- **External-tool availability checks share one policy and refuse tools found
  only through relative paths** (#14815).
- **Standalone POSIX/PowerShell installers promote a verified perllsp +
  perl-dap product unit** and inspect the archive against a versioned
  contract (#12815, #12742).
- **Docker publishes only the `perllsp` runtime image**; unsuffixed builder
  tags stop receiving updates (#15089).

VS Code extension:

- **New `.pm`/`.t` files are no longer auto-populated** — use
  **Perl: Create Module** / **Perl: Create Test** (#16515).
- **Managed binary archive downloads are bounded independently of timeout**
  and the archive is inspected before extraction (#12808).

## What improved for users

### Compiler-backed analysis substrate (foundations, shipped as data)

- The AST carries a **field-level registry of payload byte offsets** and a
  **versioned deterministic structural schema identity** with a
  freshness-gated `NodeKind` inventory (#13985, #12806).
- **Compiler-produced lexical facts** move in immutable envelopes
  (`FilePirLexicalContributionV1`) bound to exact source/generation/HIR
  identities, with a proof-population manifest for the first compiler-backed
  references/rename cohort (#12180, #12470).
- **Body-HIR lowering fidelity**: complete-program bodies reuse canonical
  lowering (#17554); lexical reads after labelled package statements,
  loop-private `foreach` iterators, package-top-level `my`, read-modify-write
  substitution targets, and `local`/declaration assignments are preserved
  (#18208, #18189, #18194, #18240, #18288, #13500).
- **Structured-mutation values for DAP** decode strict JSON with surrogate
  pairs; the `MutationStructuredValue.v1` contract is defined as domain types
  first (#12185, #12581).
- Workspace understanding gained **non-executing build-system detection** for
  ExtUtils::MakeMaker/Module::Build and Carmel, plus a deterministic
  ProjectEnvironmentSnapshot compiler with selected/rejected receipts and an
  operation-execution authorization vocabulary that fails closed
  (#18767, #14213, #13940, #14696).

### Parsing and grammar correctness (consolidated)

One broad sweep, consolidated here because the fragments describe the same
user-visible phenomenon — source that used to mis-parse or mis-recover now
parses and recovers honestly:

- **Heredocs**: deterministic byte-budget collection replaces a wall clock;
  opener-owned contracts, term-slot recognition after `return`/fat commas,
  scalar print-filehandle prose kept out of sub discovery, POD-directive
  guards, full-body folding ranges, and fuzz-found panic fixes
  (#8220, #13781, #16169, #16336, #17316, #17324, #18248, #16607, #17766).
- **Quote-like operators and word lists**: bare `q`/`qq`/`qw` arguments stay
  inside their directives, quote-like spellings in prototype text no longer
  enter quote mode, `qw` retains literal `#` words, postfix-dereference
  recovery, and the three-dot operator parses as a range
  (#16146, #16184, #18254, #17585, #14740, #18260, #18074).
- **String repetition (`x`, `x=`)**: contiguous `x=` as right-associative
  assignment, repetition operands across v-strings/quote forms, spaced and
  invalid forms reported without losing partial expressions, compound
  declaration initializers lower correctly
  (#13102, #13169, #13497, #14963, #16145, #16177, #18288).
- **Indirect calls and object forms**: `&foo(...)` is a distinct `AmperCall`
  node recognized across call hierarchy/inlay/hover/symbols, numeric-leading
  print-filehandle terms parse through the indirect-call path, parenthesized
  uppercase/qualified calls to `print`/`printf`/`say` are preserved, and
  dynamic indirect constructors record a distinct role
  (#4704, #5059, #13125, #17079, #18279).
- **Signatures, `local`, and contextual assignment**: parenthesized
  `substr`/`vec`/`pos` lvalue assignments, `local` with complex lvalues,
  residual same-line syntax reported as typed recovered parses, and
  declaration-initializer combinations keep canonical ranges
  (#13496, #13497, #13500, #13505, #14930).
- **Framework and modern-Perl objects**: `Mojo::Base` accessors/inheritance,
  Moose/Moo `:writer(NAME)` and named `field` traits, chained comparisons
  (Perl 5.32+), `catch (my/our/state $e)` diagnostics, `our`-alias
  statement-modifier visibility, and framework gating that takes the earliest
  Dancer2 `use` site and honors Dancer1 static quoted targets
  (#9682, #13283, #14997, #4702, #18282, #16108, #18659, #17488).
- **Lexer/parser internals**: budget-stop recovery contract pinned by tests,
  `MAX_DELIM_NEST` arm retirement, stack-safe exact whole-tree reads,
  iterative Node clone/equality, and incremental reuse of prior trees for
  whitespace-only edits with stale-subspan rejection
  (#14362, #14389, #12639, #12425, #12428, #12489, #13180, #14350, #13917).

### Diagnostics, navigation, and completion truthfulness

- **Regex diagnostics** publish from the parser's canonical analysis with
  exact ranges and stable `PL1000–PL1007` codes (#14751); PL406
  unreachable-code detection covers `goto LABEL` and derives from typed
  control-flow summaries (#4699, #10004); severity rendering and diagnostic
  `source` strings are coherent (#5286, #4681, #4705).
- **Receipts tell the truth about freshness**: goto-definition, references,
  and provider-decision explanations distinguish stale, dynamic, ambiguous,
  and unavailable evidence instead of presenting another request's receipt
  (#14193, #14163, #14918, #15619, #15545, #15547).
- **Completion**: no answers from stale parses mid-edit (#17834); completion
  inside string interpolation and hash-ref keys (#5271, #5157); keyword
  suggestions split by syntactic role (#14883, #5179); qualified-suffix and
  mid-token cursor replacement (#18114, #18123, #17779); method completion
  from composed roles and inherited/workspace indexes without a wedged index
  (#16850, #17045, #16651); later-declared lexicals no longer suggested
  (#5146).
- **Navigation/symbols**: Find References returns identifier-only ranges and
  shrinks declaration spans safely for non-ASCII prefixes (#18863, #18529);
  references no longer count hash-key literals as subs (#16683); hover works
  for files open on disk only, stops recommending `cpanm` on indexed symbols,
  shows the immediately preceding POD block, and preserves variable sigils in
  fallback cards (#16743, #16686, #18039, #17864); document symbols gained
  deterministic child ordering, package-extent parenting, Moose/Moo
  deduplication, and framework-aware selection (#18354, #18184, #18192,
  #18196, #18309, #17778); rename refuses comment/POD/data tokens and
  preserves sigils and Unicode names (#17554, #17792, #18012, #17980, #17791);
  type/call hierarchy traverse ancestors, `&foo` calls, and nested bodies
  correctly (#5151, #5059, #18321); workspace-symbol/resolve answers
  spec-shaped requests and capability advertisements match feature truth
  (#17692, #18325, #14181); package-cursor references resolve to the same
  identity as usages (#17157).
- **Protocol/server robustness**: malformed JSON frames, overlong lines,
  rangeLength-without-range batches, and rejected changes fail cleanly while
  preserving accepted state (#17754, #15506, #18516, #17560, #15533); the
  `exit` notification in socket mode no longer kills the whole server
  (#17374); subprocess stdin inheritance fixed on Windows (#17305); shutdown
  races deliver or refuse without writing to the wire (#15186, #16678,
  #15615); configuration reloads preserve buffer metadata (#15118, #17768,
  #18274); dependency file changes refresh open-file diagnostics and stale
  rows are cleared for closed files (#18099, #18120, #18102, #18051); CRLF/UTF-16/Unicode byte-offset exactness across
  folding, POD coverage, debugger values, and ranges (#18103, #18106, #18076,
  #17564, #18252, #18147, #5219, #4965, #4941).

### Debugger (perl-dap)

- **Stdio is the one product editor transport**; TCP listener binding is
  removed and external-peer modes validate `HOST:PORT` at startup
  (#12573, #12641, #12723, #16675).
- **Stale evidence is rejected, not replayed**: breakpoints replay only after
  engine acknowledgment; expression results, locals, stack traces, and inline
  values are discarded after resume, exit, or session change; cancellation no
  longer poisons request IDs; disconnect/terminate retire stale pending
  producers (#15488, #15566, #15576, #15584, #14453, #15491, #15738).
- **Honesty at the boundaries**: `stopOnEntry` publishes only on real Perl
  debugger frame evidence; launch/attach arguments are validated with
  actionable errors; unsupported attach modes are refused before connecting;
  evaluation preserves numeric-leading expressions and cancels blocked
  evaluations (#15220, #17738, #18050, #15521, #14402, #15631, #15614,
  #15629); external-peer failures are classified as peer failures, not
  adapter bugs (#14566).

### Packaging, installation, and release integrity

- Installers ship and verify one **perllsp + perl-dap product unit** against
  a versioned archive contract; Windows installs `perllsp.exe`; the piped
  bootstrap no longer aborts under `set -u`; `BUILD_FROM_SOURCE` runs the
  toolchain guard before network work; POSIX failures point at the right
  manual procedure; Windows verification fails on native nonzero exits
  (#12815, #12742, #4788, #5452, #15030, #16753, #17681, #16767, #14052).
- **Managed release selection is unified**: one compatibility-first route for
  first-use, repair, and update (#11613, #9978, #9992, #6754, #6756).
- Release integrity: VSIX attachment refuses tag/commit mismatch, post-publish
  smoke verifies the actually-published version from the publish commit,
  `toolchain_digest` binds the Cross container digest, cpanfile conditionals
  stay out of distribution facts, and the release-turnkey stops at typed
  manual-merge handoffs (#9597, #9593, #14376, #13649, #13681, #13890, #16851,
  #13100, #13157).
- Docker publishes only the runtime image (#15089); the orphaned Homebrew
  formula is gone; crates.io metadata is complete (#4717, #5284).

### Security hardening (consolidated)

Project configuration can no longer grant itself authority: AI completion can
only be opted out of (endpoint/key/headers never project-settable), absolute
`include_paths` in workspace `.perl-lsp.toml` are rejected, legacy
Perl::Critic/perltidy profile settings cannot be armed via project config,
AI requests validate destination hosts against policy without following
redirects, and "explain missing module" no longer leaks path-existence
information (#4955, #5022, #4991, #5021, #5023, #5025, #5029). The DAP
transport restriction (#12641/#12723) and Windows trusted-root checks with
full 128-bit directory IDs (#16986) close remote-surface holes; archive
extraction guards are fail-closed in the Vim toolchain (#18278); cargo-deny
bans fail closed on serde_yaml_ng/unsafe-libyaml (#17722); the regex scanner
no longer false-flags `(?{ ... })` text in prose (#4682); the generic
configured-command MCP passthrough is disabled (#7911); npm dependencies are
patched (brace-expansion, fast-uri/Ajv) (#5263, #15120); VS Code extension
publishing pins VSIX-to-commit integrity (#9597).

### Performance

Environment probes are cached across initialize and diagnostics cycles
(#13651); the immutable source digest is reused across lexer checkpoints
(#15457); formatting/completion hold locks narrower and release them before
serialization (#4711, #5194, #5196, #4936, #5224); the workspace-index
resource limits are actually enforced (#4701); requests respond promptly to
cancellation (#4707); the VS Code extension gained an evidence-backed client
performance policy layer and starts the server on demand (#11909, #10221).
