# SRP microcrate inventory — historical pointer

This file is retained for links to the former generated microcrate inventory. Its counts and tables were generated during the pre-collapse workspace and are not a current crate inventory.

Use these authorities for current work:

- [Cargo.toml](../Cargo.toml) for exact workspace membership and exclusions;
- [Architecture Overview](reference/ARCHITECTURE.md) for current crate families and ownership;
- [Publishing after the collapse](project/PUBLISHING_AFTER_COLLAPSE.md) for the surviving publish topology;
- package-local manifests and READMEs for current size, dependency, and API decisions.

The old family counts, split candidates, crate names, LOC figures, and collapse status are historical snapshots. Do not use them to decide whether a crate exists, whether a concern should be extracted, or how a current change should be scoped. If a new inventory is needed, regenerate it from the current workspace and label the resulting receipt with its source revision and command.
