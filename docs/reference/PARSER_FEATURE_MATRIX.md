# Parser Feature Matrix — compatibility pointer

This file is retained for links from older issue and release material. The checked-in matrix was generated from an old commit and reports aggregate percentages without a current reproducible receipt; it is not a current parser-coverage authority.

Use the current evidence surfaces instead:

- [Parser status](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/project/status/parser.md) — current parser evidence and bounded status;
- [Current status](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/project/CURRENT_STATUS.md) — published status and receipts;
- [perl-corpus](https://github.com/EffortlessMetrics/perl-lsp-swarm/tree/main/crates/perl-corpus) — fixtures and manifest-backed parser-accuracy evidence;
- [features.toml](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/features.toml) — capability policy, not a parser-coverage measurement;
- [parser limitations](https://github.com/EffortlessMetrics/perl-lsp-swarm/blob/main/docs/reference/PARSER_LIMITATIONS.md) — static-analysis boundaries.

A fixture selection or successful parse slice does not establish complete Perl coverage. Preserve the exact subject, source revision, runner, and result when publishing new measurements.
