# perl-lsp Current Status

> Stable entry point for status and evidence in `perl-lsp-swarm`.
> The [status guide](status/index.md) routes readers to the owning dashboards,
> receipts, and live GitHub controllers.

## Find the Right Dashboard

| What you need | Where to start |
| --- | --- |
| Release decisions, blockers, and next work | [Release and next work](status/index.md#release-and-next-work) |
| Editor, LSP, debugger, and native-tooling behavior | [Product and editor behavior](status/index.md#product-and-editor-behavior) |
| Parser corpus, compiler facts, and provider coverage | [Parser and compiler](status/index.md#parser-and-compiler) |
| Test debt, performance, memory, and verification | [Reliability and proof](status/index.md#reliability-and-proof) |
| How to interpret a count, baseline, or receipt | [Read the evidence](status/index.md#read-the-evidence) |
| How to refresh generated observations | [Refresh and maintain](status/index.md#refresh-and-maintain) |

Use the linked live controllers for current release and freeze decisions. Check
each receipt's date, source revision, environment, and tested scope before using
its result. The status guide links workspace/package facts to their source owners
and keeps development evidence separate from public-channel observations.
