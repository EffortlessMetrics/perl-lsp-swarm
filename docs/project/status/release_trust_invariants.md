## Claim boundaries

- `blocked_or_not_proven_child_as_pass`: Aggregation honesty only: a child not_proven or blocked result cannot appear as a clean fan-in. Does not consume live receipts.
- `broken_documented_install`: Documented install route integrity for the topology-selected path. Does not prove public-channel currentness.
- `duplicate_or_late_terminal_outcome`: Request/lifecycle uniqueness: one terminal outcome per accepted request. Seeded from the #8507 process family; not a live receipt.
- `false_exact`: Provider/currentness truth: a confident wrong exact answer. Not broad feature correctness.
- `false_repair_diagnosis`: Startup diagnosis must follow evidence. Missing health evidence cannot become a fabricated repair class.
- `missing_required_publication_subject`: Release-integrity subject completeness. Seeded from the #8507 publication family; no live closeout is consumed.
- `missing_required_subject`: Candidate-controller spelling from #4350 for a missing required subject. Distinct from missing_required_publication_subject; later producer-binding may alias them.
- `mixed_generation_or_root_result`: One root/generation cannot supply another root's or generation's answer.
- `mixed_version_readiness`: Mismatched VSIX/server/DAP versions or hashes cannot report ready.
- `no_publish_external_mutation`: No-publish rehearsal public-state stability. Seeded from the #8507 authority family; observers are not executed here.
- `optional_tool_false_requirement`: Optional external tools absent must not fail native product health unless that path is selected.
- `orphaned_candidate_process`: Candidate rehearsal process cleanup. Distinct from installed-server/debuggee cleanup.
- `orphaned_server_or_debuggee`: Installed server/debuggee process cleanup after shutdown.
- `partial_artifact_promotion`: Partial or unpaired artifact promotion cannot report ready.
- `partial_or_checksum_invalid_install`: Candidate-controller spelling from #4350 for checksum-invalid or partial install acceptance.
- `partial_release_promotion`: Partial artifact or channel set promotion. Seeded from the #8507 publication family.
- `partial_text_transaction_commit`: Full-document transaction atomicity. Seeded from the #8507 text-sync family; producers are not wired here.
- `ranged_change_while_desynchronized`: Ranged input must not mutate last-good source under the selected full-document UTF-16 envelope.
- `silent_startup_failure`: Startup must not fail silently. First-ten-minutes and installed journey share this zero-budget ID.
- `stale_effect_after_generation`: Old-generation effects cannot publish after an accepted newer generation. Seeded from the #8507 process/currentness family.
- `stale_exact`: Exact answers that survive an edit/delete/rename of their subject.
- `unapproved_public_mutation`: Effective public mutation authority during no-publish rehearsal.
- `unexplained_success_empty`: Not-ready, dynamic, or instrument-failed empty cannot flatten to legitimate successful empty.
- `unreachable_required_manifest_surface`: Installed-required package contributions must be reached in the exact VSIX journey, not only statically registered.
- `unreviewed_public_claim`: Public claims must match the reviewed candidate-bound catalog. No live catalog execution here.
- `unsafe_edit`: Edit-authorizing operations require complete exact current facts. Partial or prior facts cannot authorize.
- `wrong_binary_or_artifact`: Candidate-controller spelling from #4350 for wrong binary/artifact identity. Distinct from installed wrong_binary_or_version.
- `wrong_binary_or_version`: Installed identity: the executed binary/version must be the candidate, not workspace/PATH/stale-cache.
- `wrong_or_cross_sha_subject`: Checksum/SBOM/attestation subjects must bind the exact candidate SHA. Seeded from the #8507 publication family.
- `wrong_target_or_silent_fallback`: Unsupported architecture cannot silently select another target.
- `wrong_target_or_version`: Candidate-controller spelling from #4350 for wrong target/version selection. Distinct from wrong_target_or_silent_fallback.
