## Claim boundaries

- **`calls.ampersand` (#5242):** Ampersand syntax, prototype bypass, argument forwarding, and callee identity are not normalized.
- **`calls.normalized_semantics` (#5242):** Several physical call forms exist, but syntax, dispatch, callee identity, operands, and prototype/context contracts are not yet one canonical projection.
- **`context.value_context` (#2275):** Context dimensions are named by the compiler roadmap but are not yet fully propagated through every canonical operation and edge.
- **`control.default` (#6674):** Default-arm identity and control edges are not represented in canonical body/PIR state.
- **`control.given` (#6674):** Feature/version state, topicalization, arm control, and smartmatch semantics are absent.
- **`control.postfix_modifier` (#4886):** Flat/body shells exist; canonical PIR branch/loop edges and loop-control composition remain spec-gated.
- **`control.when` (#6674):** Arm ordering, topicalized comparison, and version-specific smartmatch behavior are absent.
- **`declarations.nested_variable_list` (#6659):** Parent declaration traversal retains entries, but no canonical nested-list identity or place graph is proven.
- **`dynamic.tie` (#6683):** Tie lifecycle, target place, hidden method effects, and capability boundaries are not represented.
- **`dynamic.untie` (#6683):** Untie and tied-place lifetime/destructor consequences are not represented.
- **`exceptions.defer` (#6661):** A flat marker exists; registration order and cleanup obligations on every exit path are not modeled.
- **`exceptions.try` (#6661):** A flat shell exists; exception regions, handlers, bindings, and exceptional CFG are not canonical.
- **`formats.declaration` (#6675):** Scope/stash metadata exists; specialized format source, slot identity, and execution capability remain incomplete.
- **`namespaces.typeglob` (#6668):** Some assignments emit stash facts or boundaries, but typeglob value, slot, alias, and localization semantics are not canonical.
- **`objects.core_class` (#6672):** ClassDecl is a declaration shell; fields, MRO, construction, method lookup, and EIR-ready object semantics are not established.
- **`operators.binary` (#6658):** Body HIR has a generic binary node; operator families, context, short-circuiting, and executable semantics remain unproven.
- **`operators.chained_comparison` (#6658):** The parser distinguishes the construct, but canonical body/PIR semantics and evaluate-once ordering are absent.
- **`phases.begin` (#6664):** Phase facts are recorded, but source/phase ordering, applied state, and lifecycle execution remain incomplete.
- **`places.array_slice` (#5244):** Traversal/read recovery exists through a generic bridge; ordered evaluate-once slice-place semantics are not modeled.
- **`places.hash_slice` (#5244):** Traversal/read recovery exists through a generic bridge; ordered evaluate-once slice-place semantics are not modeled.
- **`places.key_value_slice` (#5244):** The key/value result shape and ordered selector places are not yet first-class.
- **`regex.literal` (#4848):** A flat shell and embedded-code boundary exist; canonical body/PIR regex operation semantics remain issue-owned.
- **`regex.match` (#4848):** Flat target facts exist; body/PIR target, context, capture, and match-state semantics remain incomplete.
- **`regex.substitution` (#4848):** Flat mutation/modifier facts exist; canonical place, replacement, capture, and embedded-code semantics remain incomplete.
- **`regex.transliteration` (#4848):** A flat shell exists; target-place mutation, modifiers, and executable semantics remain incomplete.
- **`source.data_section` (#6675):** The parser recognizes the marker, but compiler stop/payload identity and runtime DATA capability are not modeled.
- **`source.ellipsis` (#6675):** Parsed syntax is not yet represented as a deliberate control/runtime boundary.
- **`values.v_string` (#6658):** Parser classification exists; typed value representation and version-sensitive semantics do not.
