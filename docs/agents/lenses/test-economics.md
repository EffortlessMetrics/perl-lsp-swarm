# Test-economics lens

Choose the cheapest proof layer that still discriminates the claim.

Ask:

- what realistic wrong implementation still passes;
- whether the oracle is independent and non-vacuous;
- whether the opposite direction is represented;
- whether production composition must be exercised;
- whether a unit, component, integration, packaged, real-workspace, or external-oracle test is required;
- whether broad proof is being used to compensate for a missing focused oracle.

Return the minimum credible proof set, its limitations, and any broader evidence that remains proportionate.
