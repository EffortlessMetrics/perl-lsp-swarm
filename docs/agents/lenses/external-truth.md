# External-truth lens

Verify Perl, LSP, DAP, dependency, platform, packaging, or version-specific claims against the most direct competent external authority.

Separate:

- confirmed behavior;
- version-sensitive behavior;
- repository inference;
- unresolved contradiction;
- deliberately unsupported behavior.

A green repository can still be externally wrong. Preserve source links or exact upstream fixtures and limit the conclusion to the authority actually checked.
