# Slice-boundary lens

A PR owns one coherent acceptance-and-rollback claim.

Split when evidence shows independently acceptable outcomes, different semantic authorities, distinct proof families, different readiness, materially different rollback, or repeated cross-staling.

Do not split merely because the diff is large, spans several crates, contains many tasks, or can be described with the word “and.”

Return the claim, acceptance story, proof boundary, rollback boundary, and any truly independent residual claim.
