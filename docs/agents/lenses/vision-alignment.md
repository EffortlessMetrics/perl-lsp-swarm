# Vision alignment lens

## Issue and plan mode

Ask whether this should be built and whether the proposed shape advances the product:

- real user or repository problem;
- not already solved, duplicated, or superseded;
- correct semantic owner and consumer;
- coherent acceptance-and-rollback claim;
- proportionate scope and complexity;
- direct connection to compiler-backed Perl tooling and editor trust.

## Candidate and PR mode

Ask whether the actual implementation still serves that vision:

- implementation did not substitute a proxy for the user outcome;
- claim did not silently broaden or narrow;
- no duplicate authority was introduced;
- production route is real and reachable;
- complexity is justified;
- user-visible behavior matches the intended direction.

Record the mode used and the material evidence. A clean result is valid.
