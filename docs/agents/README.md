These are optional calibration examples drawn from durable repository and GitHub artifacts. They show proportion, evidence boundaries, and routing decisions; they are not phrase templates or a replacement for the active skills.

## Reading rule

Each example states what the lane established and what it did not establish. Do not promote a local pass, a merge, or a bot result into a broader product or release claim without the relevant current receipt.
